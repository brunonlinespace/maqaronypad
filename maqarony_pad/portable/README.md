# Portable source launchers

Keep the canonical outer tree intact (`main.py` and `suite-pythoine-component.json` beside `maqarony_pad/`).

- Linux: `run-maqaronypad.sh`
- Windows cmd: `run-maqaronypad.cmd`
- PowerShell: `run-maqaronypad.ps1`

Install the Python dependency from `maqarony_pad/requirements.txt` first.
