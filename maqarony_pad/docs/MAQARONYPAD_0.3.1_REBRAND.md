# MaqaronyPad 0.3.1 — Rebranding pilot

**Direct predecessor:** Markopad 0.2.10 (provided authoritative source archive).

**Scope:** Standalone application and packaging identity renamed from Markopad to MaqaronyPad; embedded source editor/preview technology renamed to `mwpyn`; application logo assets replaced from owner-supplied `MaqaronyPad` set. **Command/toolbar/Ribbon icon bytes are unchanged.**

**Protected behavior:** source-authoritative Markdown, unchanged Qt Markdown preview semantics, external-file handling, no-clobber saves/duplicates, file-size safety, permissions, keyboard shortcuts, status, Classic/Modern toolbar and theme behavior.

**Configuration:** clean new path, no automatic migration of former Markopad settings. Historical release/tag/branch states are not modified.

**Availability:** source pilot only. Fedora/AppImage and GUI smoke require supported Qt runtime/host tests; no GitHub release or repository rename is performed by this package.
