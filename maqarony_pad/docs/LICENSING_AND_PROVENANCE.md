Markopad is GPLv3-or-later.

Markopad originated as an independent Markdown-only fork of the user's preserved Ricopad 0.5.0 codebase. The source editor architecture carries forward the Sheepy Pad/Timblee Pad-informed source-editing work already integrated into Ricopad. Markopad 0.0.2 retains that lineage while using its own Markdown-only architecture, approved teal M/down-arrow application identity, and approved traditional neutral-plus-teal toolbar icon language.
